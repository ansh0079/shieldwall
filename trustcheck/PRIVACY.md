# TrustCheck beta privacy notice

Last updated: 10 November 2026

TrustCheck checks the domain of the shop you are visiting and limited page signals needed to identify shopping, checkout, company-registration and order-confirmation pages. When the managed backend is enabled, TrustCheck sends the shop domain, the shop origin, and a company number displayed by the shop when available. It does not send the full checkout URL.

Optional order reminders store the shop domain, date, optional visible amount, storefront name and a one-way hash of the order identifier on your device. TrustCheck does not store or send your name, email, delivery address, account credentials, card details, PayPal details, or raw order number. Turning reminders off prevents new reminders from being created.

If you answer an order reminder or submit a buyer report, the backend receives the shop domain, outcome, selected problem categories, dates and an anonymous server-issued installation credential. Raw installation identifiers are stored only as salted hashes. IP addresses are used temporarily in memory for abuse rate limiting and are not written with reports.

TrustCheck may contact RDAP services, the Internet Archive, configured security services, Companies House, and the TrustCheck backend to provide checks. A direct Trustpilot link is available without importing a rating. Trustpilot ratings are displayed only when licensed API access is configured.

Community results remain hidden until a minimum number of independent reports is reached. Beta data is retained for up to 180 days. Access to order-outcome exports is restricted to the TrustCheck administrator.

Before public distribution, replace this paragraph with the operator's legal name, contact email, hosted privacy URL, deletion-request process, and applicable jurisdiction.
