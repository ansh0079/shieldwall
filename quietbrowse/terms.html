What QuietBrowse is

QuietBrowse is a browser extension that blocks ads and trackers, applies cosmetic filters, and offers optional security-related features (phishing warnings, download filename checks, password clipboard protection). It is not antivirus software and is not affiliated with Microsoft Defender, Windows Defender, or any other security product.

Heuristic features are not guarantees

Phishing warnings use local heuristics (lookalike domains, risky TLDs, unencrypted login forms, etc.). They can produce false positives and false negatives. Always verify sites yourself before entering passwords or payment details.

Download guard inspects file names and extensions only. It does not scan file contents for malware. Keep a real antivirus program enabled.

Trust scores in the popup are informational estimates, not security certifications.
