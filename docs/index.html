QuietBrowse

Ads and trackers stop on your device — not in someone else’s cloud.

Get the extension Privacy

Install

Chrome / Edge / Brave — clone this repository, open chrome://extensions, enable Developer mode, and choose Load unpacked with the project folder. A Chrome Web Store build will be linked here when published.

Firefox — run npm run build:xpi, then install the generated .xpi from about:debugging.

What you get

A privacy-first blocker that explains what it does — learning, trust score, Fix this site — with blocking quality close enough that you don’t leave for something heavier.

Local-only by design

No accounts, analytics, or developer servers. Settings and stats stay on your machine.

Real filter lists

EasyList and EasyPrivacy with optional Fanboy and regional lists, updated on your schedule.

Breakage escape hatch

Pause a site instantly, zap leftover elements, and keep a local report if something broke.
